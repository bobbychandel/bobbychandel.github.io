PUBLISH USING FREE GITHUB PAGES:
1. Create/sign in to GitHub: https://github.com/
2. Choose a username. For the clean address bobbychandel.github.io, the username must match the part before .github.io.
3. Create a public repository named exactly bobbychandel.github.io.
4. Upload all package files and the assets folder into the repository root.
5. In repository Settings > Pages, choose deployment from the main branch/root if not enabled automatically.
6. Wait for deployment, then open https://bobbychandel.github.io/.
7. Replace bobbychandel in canonical URL, Open Graph URL/image, JSON-LD URL/image, robots.txt and sitemap.xml BEFORE publishing; commit the changes.
8. In Google Search Console, add the URL-prefix property https://bobbychandel.github.io/ and follow verification instructions. Submit /sitemap.xml. A free github.io subdomain does not provide the same DNS control as a custom domain.
9. Check the site on mobile and test the image URL.
10. Only add verified factual claims, project details, media links and articles.
